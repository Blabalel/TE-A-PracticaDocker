# TRICODESISTEMS - Sitio Web Institucional

## 📌 Descripción del Proyecto

**TRICODESISTEMS** es una startup dedicada al desarrollo de soluciones tecnológicas modernas y eficientes.

Este proyecto consiste en el desarrollo de su **sitio web institucional**, creado como una aplicación web estática, ligera y totalmente contenedorizada mediante **Docker**.

El objetivo principal es disponer de una aplicación que pueda ejecutarse de manera **reproducible y consistente** en diferentes equipos y ambientes de desarrollo o producción.

## 🛠️ Tecnologías Utilizadas

### HTML5
Utilizado para construir la estructura semántica y el contenido del sitio web.

### CSS3
Utilizado para diseñar la interfaz, aplicar estilos modernos y garantizar un diseño responsivo y adaptable a diferentes dispositivos.

### JavaScript (ES6)
Utilizado para implementar la interactividad y funcionalidades dinámicas del sitio web.

### Docker
Utilizado para empaquetar la aplicación dentro de un contenedor, permitiendo que pueda ejecutarse de forma consistente en diferentes ambientes.

### Nginx
Utilizado como servidor web para entregar los archivos estáticos de la aplicación.
